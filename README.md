# 경력 계산기 (민법 역법)

엑셀 `경력계산기(ver. 20181112)`의 계산식을 웹앱으로 옮긴 정적 사이트입니다. 서버·빌드 과정이 없습니다.

## 기능
- 날짜 입력은 `2026-3-1`, `2026/3/1`, `20260301` 외에 **연도 두 자리**(`21/2/20`, `210220`)도 가능 — 올해+10년 이하는 2000년대, 초과는 1900년대로 해석
- 시작일·종료일(양 끝 포함)로 년·월·일 계산 — 엑셀 I·J·K열 수식과 동일
- 여러 건 합산 (30일=1개월, 12개월=1년) — 엑셀 I30:K30과 동일
- 합산을 **중복 경력 포함**(엑셀과 동일)과 **중복 경력 제외**(겹친 기간을 한 번만 계산) 두 가지로 표시
- **중복 기간 검출**: 겹치는 두 행과 겹친 구간을 `경고) 2026. 2. 1.~2026. 3. 30. (1개월 29일 중복)` 형태로 표시
- **사람별 보관함** 최대 100명 (쿠키 또는 브라우저 저장소), 백업 내보내기/불러오기(JSON)

## 파일 구성
```
public/           배포되는 사이트 (이 폴더만 공개됨)
  index.html, style.css, _headers
  js/calc.js      계산 로직 (엑셀 수식 이식)
  js/storage.js   사람별 저장 (쿠키 / localStorage)
  js/app.js       화면 동작
wrangler.jsonc    Cloudflare Workers(정적 파일) 배포 설정
test/             검증용 스크립트 (배포되지 않음)
```

## 배포 (GitHub → Cloudflare)
이 저장소를 GitHub에 올린 뒤, 아래 둘 중 하나로 연결합니다. 둘 다 `public/` 폴더만 공개합니다.

**A. Workers (Cloudflare 권장, 새 프로젝트 기본)**
1. Workers & Pages → Create → Import a repository → 저장소 선택
2. Build command: 비움 / Deploy command: `npx wrangler deploy` (기본값 그대로)
3. Deploy. 이후 `git push` 때마다 자동 배포됩니다. (`wrangler.jsonc`가 설정을 담고 있음)

**B. Pages**
1. Workers & Pages → Create → Pages → Connect to Git
2. Framework preset: None / Build command: 비움 / Build output directory: `public`

## 저장 방식 주의
- 기본은 **쿠키**입니다. 쿠키는 사이트에 접속할 때마다 서버로 함께 전송되며 쿠키 1개당 약 4KB 제한이 있어,
  전체 12KB를 넘으면 저장을 거부합니다(한도를 넘겨 헤더가 너무 커지면 사이트 접속 자체가 막힐 수 있기 때문).
- 사람이 많거나 기록이 길면 화면 아래 **저장 방식 → 브라우저 저장소**로 바꾸세요(기존 데이터 자동 이전).
- 코드에서 기본값을 바꾸려면 `public/js/storage.js`의 `init()`에서 `if (!mode) mode = 'cookie'` 를 `'local'`로 수정합니다.
- 입력한 데이터는 서버로 수집되지 않고 브라우저에만 저장됩니다.

## 계산 규칙 요약
- 기간은 시작일·종료일을 모두 포함합니다.
- 시작일의 전일이 종료일 달의 같은 날짜이면 만(滿) 1개월, 시작일이 1일이면 종료일이 월말일 때 만 1개월.
- 남는 일수가 30일이면 29일로 처리(엑셀 수식 동일).
- 근거: 2017 공무원보수 등의 업무지침(인사혁신처 예규 제35호, 2017.1.20)

## 인정 경력
‘중복 경력 제외 합산’을 기준으로, 일수가 **15일 이상이면 1개월로 올림**하고 15일 미만이면 버려 `N년 N개월`로 표시합니다. (1년 1개월 15일 → 1년 2개월 / 1년 1개월 14일 → 1년 1개월)

## 중복 경력 제외 합산
하루라도 겹치는 기간들을 하나로 합친 뒤, 합친 기간마다 년·월·일을 계산해 합산합니다. 맞닿기만 한 기간(종료일 다음날이 시작일)은 합치지 않으므로, 중복이 없으면 두 합산은 항상 같습니다.

## 검증
`test/` 에 엑셀 수식과 대조한 방법이 있습니다. 무작위 6,003개 기간과 20행 합산 6건을 LibreOffice로 엑셀 수식을 재계산해 비교했고 모두 일치했습니다.
