# 경력 계산기 (민법 역법)

엑셀 `경력계산기(ver. 20181112)`의 계산식을 웹앱으로 옮긴 정적 사이트입니다. 서버·빌드 과정이 없습니다.

## 기능
- 날짜 입력은 `2026-3-1`, `2026/3/1`, `20260301` 외에 **연도 두 자리**(`21/2/20`, `210220`)도 가능 — 올해+10년 이하는 2000년대, 초과는 1900년대로 해석
- **경력 산정 기준일**(화면 최상단): 종료일을 비워 둔 경력은 기준일까지 계산 (기준일을 비우면 오늘). 기준일도 저장됨
- 시작일·종료일(양 끝 포함)로 년·월·일 계산 — 엑셀 I·J·K열 수식과 동일
- 여러 건 합산 (30일=1개월, 12개월=1년) — 엑셀 I30:K30과 동일
- 합산을 **중복 경력 포함**(엑셀과 동일)과 **중복 경력 제외**(겹친 기간을 한 번만 계산) 두 가지로 표시
- **중복 기간 검출**: 겹치는 두 행과 겹친 구간을 `경고) 2026. 2. 1.~2026. 3. 30. (1개월 29일 중복)` 형태로 표시
- **사람별 보관함** 최대 1000명 (브라우저 저장소 기본, 쿠키 선택 가능), 백업 내보내기/불러오기(JSON)

## 파일 구성
```
public/           배포되는 사이트 (이 폴더만 공개됨)
  index.html, style.css, _headers
  js/calc.js      계산 로직 (엑셀 수식 이식)
  js/storage.js   사람별 저장 (쿠키 / localStorage)
  js/app.js       화면 동작
wrangler.jsonc    Cloudflare Workers(정적 파일) 배포 설정
test/             검증용 스크립트 (배포되지 않음)
```

## 배포 (GitHub → Cloudflare)
이 저장소를 GitHub에 올린 뒤, 아래 둘 중 하나로 연결합니다. 둘 다 `public/` 폴더만 공개합니다.

**A. Workers (Cloudflare 권장, 새 프로젝트 기본)**
1. Workers & Pages → Create → Import a repository → 저장소 선택
2. Build command: 비움 / Deploy command: `npx wrangler deploy` (기본값 그대로)
3. Deploy. 이후 `git push` 때마다 자동 배포됩니다. (`wrangler.jsonc`가 설정을 담고 있음)

**B. Pages**
1. Workers & Pages → Create → Pages → Connect to Git
2. Framework preset: None / Build command: 비움 / Build output directory: `public`

## 저장 방식 주의
- 기본은 **브라우저 저장소(localStorage)**입니다(v1.9.0~). 1000명까지 쓸 수 있고(브라우저 저장 용량 한도 내) 서버로 전송되지 않습니다.
- 화면 아래 **저장 방식**에서 **쿠키**로 바꿀 수 있습니다(기존 데이터 자동 이전). 쿠키는 접속할 때마다 서버로 함께 전송되고 쿠키 1개당 약 4KB, 전체 12KB 제한이 있습니다.
- 이전 버전에서 쿠키로 저장해 둔 데이터가 있는 브라우저는 데이터 보존을 위해 쿠키 방식이 유지됩니다(원하면 저장 방식을 바꾸세요).
- 입력한 데이터는 서버로 수집되지 않고 브라우저에만 저장됩니다.

## 계산 규칙 요약
- 기간은 시작일·종료일을 모두 포함합니다.
- 시작일의 전일이 종료일 달의 같은 날짜이면 만(滿) 1개월, 시작일이 1일이면 종료일이 월말일 때 만 1개월.
- 남는 일수가 30일이면 29일로 처리(엑셀 수식 동일).
- 근거: 2017 공무원보수 등의 업무지침(인사혁신처 예규 제35호, 2017.1.20)

## 인정 경력
‘중복 경력 제외 합산’을 기준으로, 일수가 **15일 이상이면 1개월로 올림**하고 15일 미만이면 버려 `N년 N개월`로 표시합니다. (1년 1개월 15일 → 1년 2개월 / 1년 1개월 14일 → 1년 1개월)

## 중복 경력 제외 합산
하루라도 겹치는 기간들을 하나로 합친 뒤, 합친 기간마다 년·월·일을 계산해 합산합니다. 맞닿기만 한 기간(종료일 다음날이 시작일)은 합치지 않으므로, 중복이 없으면 두 합산은 항상 같습니다.

## 검증
`test/` 에 엑셀 수식과 대조한 방법이 있습니다. 무작위 6,003개 기간과 20행 합산 6건을 LibreOffice로 엑셀 수식을 재계산해 비교했고 모두 일치했습니다.

## 인사기록(인사카드) PDF 불러오기 (v1.5.0)

개인인사기록 PDF를 올리면 **이름·소속·직위**와 **총경력 · 부장 · 학교폭력 · 파견 · 휴직 · 전문직 경력**을 카드 6장으로 한눈에 보여줍니다(v1.6.0).

- PDF는 **브라우저 안에서만** 읽습니다(서버로 전송 안 함). 저장되는 것은 이름·소속·직위와 구분·시작일·종료일뿐입니다(주민번호·주소 등은 읽지 않음).
- 파싱: pdf.js(Apache-2.0, `public/js/vendor/`, 약 1.8MB, 처음 업로드할 때만 지연 로딩)로 글자 좌표를 읽어 `16.경력`, `12.가산점` 표를 행 단위로 복원합니다.
- 분류: 휴직·정직·직위해제(복직 제외)=휴직 등(총경력·부장에서 차감) / 직위에 '부장' 포함=재직·부장 / 가산점의 영역이 '학교폭력'=학교폭력 / '파견'(파견복귀 제외)=파견 / 장학관·장학사·교육연구관·교육연구사·전문직=전문직. 파견·전문직은 총경력에 포함되고, 휴직은 총경력에서 차감됩니다.
- 종료일이 없거나 기준일보다 뒤인 기간은 경력 산정 기준일로 잘라 계산합니다.
- 상세 기록의 체크박스로 항목별 반영 여부(예: 육아휴직 차감)를 바꿀 수 있습니다.
- 배포: `public/js/pdf-career.js`, `public/js/vendor/*` 가 새로 추가되었고 CSP(`_headers`)에 `worker-src 'self' blob:` 가 필요합니다.
- 테스트: `node test/pdf_career_test.js`, 실제 PDF 검증은 `PDF_SAMPLE=파일경로 python3 -I test/e2e.py`.

## v1.20.0 — 첫 채용 자동 제외 · 재직 행 합치기 · 카테고리 묶기/색상

- **첫 채용 자동 제외**: PDF에서 가장 이른 재직 행의 발령 사유가 공채·신규채용·특별채용·경력채용 등이면 종류 `H`(첫 채용, 중복)로 표시하고 기본 제외합니다. 다른 재직/부장/파견/전문직/휴직 행이 그 기간 전체를 끊김 없이 덮을 때만 적용하며, 상세 기록의 체크로 되돌릴 수 있습니다.
- **입력창 행 합치기**: `카테고리별로 묶기`(기본 ON)이면 재직은 이어지는 구간을 하나로 합치고, 부장·파견·전문직은 종류별로 합쳐 휴직 기간을 뺀 행으로 채웁니다. 해제하면 PDF 원본 행(휴직 제외)이 시간순으로 채워집니다. 직접 수정한 입력창은 토글 시 확인 후 덮어씁니다.
- **색 표시**: 재직 청록 / 부장 보라 / 파견 주황 / 전문직 초록 (메모 값 기준).
- **주의**: 재직 행은 부장·파견·전문직 기간으로 쪼개지 않습니다(쪼개면 종료일 처리 때문에 카드 합계와 2일 어긋남). 따라서 해당 행과의 중복 경고는 설계상 남을 수 있습니다.

## v1.22.0 — 휴직 기간 산입 선택

PDF의 휴직·정직·직위해제 기간이 입력창에 ‘휴직’ 줄(붉은색)로 들어가며 ‘포함’ 체크는 **기본 해제**입니다. 체크하면 그 기간이 경력에 더해집니다(재직 줄은 휴직 기간을 뺀 채로 채워지므로 겹치지 않음). PDF 카드(총경력 등)는 기존대로 휴직을 뺀 값이며, 입력창 합계만 체크에 따라 달라집니다.

‘인사기록 PDF로 한눈에 보기’ 카드에 접기/펼치기 버튼을 넣었습니다. 이름을 입력해 추가한 사람은 기본으로 접힌 채 시작하고, PDF를 불러오면 자동으로 펼쳐집니다. 접기 상태는 사람별로 이 브라우저에 기억됩니다.

## v1.24.0 — 휴직 종류 · PDF 사람 지정 규칙

- **휴직 종류 표시**: 입력창 ‘휴직’ 줄의 내용이 PDF 임용구분 값(예: `육아휴직(첫째)`)으로 채워집니다. 종류를 못 읽으면 ‘휴직’. 여러 휴직이 이어지면 `·`로 연결합니다. 쿠키 저장 방식에서는 종류를 보관하지 않습니다.
- **PDF는 PDF의 이름으로 사람을 정함**: 같은 이름이 없으면 새 사람을 만들고 기존 사람(예: 홍길동)의 데이터는 건드리지 않습니다. 이름만 먼저 만든 같은 이름의 사람이 있으면 그 사람에 채웁니다.
- **같은 이름의 인사기록이 이미 있으면** `다시 불러오겠습니까?` 확인창을 띄우고, 확인하면 그 사람의 PDF 결과와 입력창을 새 PDF로 바꿉니다(취소하면 변화 없음).

## v1.25.0 — 이름 자동 지정
