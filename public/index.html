여러 사람 출력

출력할 사람을 선택하면 한 사람당 A4 한 장씩 이어서 인쇄합니다. (PDF로 저장도 가능)

    설정

    기본 경력 포함 설정

    인사기록 PDF를 불러올 때 아래 경력을 처음부터 체크(총경력에 포함)한 상태로 채웁니다. 바꾸면 이미 저장된 사람들의 해당 줄(군 경력, 육아휴직)에도 바로 적용됩니다. (질병휴직·정직·직위해제는 항상 체크 해제로 시작)

    출력 순서 설정

    항목을 끌어서 순서를 바꾸세요. 경력 카드, PDF 요약 표, 결과 복사, 한 장 인쇄에 모두 적용됩니다. (▲▼ 버튼으로도 옮길 수 있습니다)

      경력 계산기

      민법 역(曆)에 의한 계산 · 시작일과 종료일을 모두 포함하여 계산합니다

      불러오는 중…

      종료일을 비워 둔 경력은 이 날짜까지 계산합니다. (비워 두면 오늘 날짜)

      표창 검정 유공기간·표창 기준일에 휴직·파견 등이 있는지 확인

      표창검정은 3개까지 따로 입력할 수 있습니다. 유공기간 동안과 표창 기준일 당일에 체크한 경력(육아휴직·그 외 휴직·파견)이 걸치면 표창불가이고, 정직·직위해제는 항상 불가입니다. 육아휴직·파견 중에도 표창을 받을 수 있으면 체크를 해제하세요. 인사기록 PDF를 불러온 사람만 판정할 수 있고, 나머지는 ‘확인불가’입니다. 불가 사유는 이름 옆(제목 아래)과 아래 목록에 표시됩니다.

          최대 1000명까지 이 브라우저에 기억합니다.

          📄

          또는 인사기록(인사카드) PDF를 첨부하세요

          인사기록카드(전체) 파일을 첨부하십시오.

          PDF를 여기에 끌어다 놓거나 아래 버튼을 누르면 이름·소속과 총경력·부장·연구학교·학교폭력 예방기여·파견·휴직 경력이 자동 입력됩니다.
          PDF로 입력 시 서버에 저장하지 않습니다.

          인사기록 PDF로 한눈에 보기

          인사기록카드(전체) 파일을 첨부하십시오. 인사카드(개인인사기록) PDF를 올리면 이름·소속과 총경력 · 부장 · 연구학교 · 학교폭력 예방기여 · 파견 · 휴직(· 전문직) 경력을 자동으로 계산합니다. PDF로 입력 시 서버에 저장하지 않습니다. 파일은 이 브라우저 안에서만 읽고 서버로 보내지 않으며, 이름·소속·직위와 경력 기간(날짜)만 저장합니다.

          PDF 파일을 여기에 끌어다 놓거나 PDF 불러오기를 누르세요 (여러 개를 한꺼번에 선택해도 각각 따로 입력됩니다)
          PDF의 이름으로 사람별 보관함에 새로 추가됩니다. (같은 이름이 이미 있으면 확인 후 다시 불러옵니다)
          인사기록카드(전체) 파일을 첨부하십시오.

          인식된 기록 보기 · 반영 여부 수정

          체크를 끄면 그 기록은 계산에서 빠집니다. ‘휴직 등’은 총경력·부장 경력에서 빼는 기간이며, 체크를 끄면 근무한 것으로 봅니다.
