유공기간 동안과 표창 기준일 당일에 휴직·정직·직위해제·파견이 걸치면 표창불가입니다. 인사기록 PDF를 불러온 사람만 판정할 수 있고, 나머지는 ‘확인불가’입니다. 결과는 이름 옆과 사람별 보관함에도 표시됩니다.

      PDF를 여기에 끌어다 놓거나 아래 버튼을 누르면 이름·소속과 총경력·부장·연구학교·학교폭력 예방기여·파견·휴직 경력이 자동 입력됩니다.
      PDF로 입력 시 서버에 저장하지 않습니다.

      인사기록 PDF로 한눈에 보기

      인사기록카드(전체) 파일을 첨부하십시오. 인사카드(개인인사기록) PDF를 올리면 이름·소속과 총경력 · 부장 · 연구학교 · 학교폭력 예방기여 · 파견 · 휴직(· 전문직) 경력을 자동으로 계산합니다. PDF로 입력 시 서버에 저장하지 않습니다. 파일은 이 브라우저 안에서만 읽고 서버로 보내지 않으며, 이름·소속·직위와 경력 기간(날짜)만 저장합니다.

      PDF 파일을 여기에 끌어다 놓거나 PDF 불러오기를 누르세요
      이미 입력된 사람이 있으면 새 사람으로 추가됩니다.
